# DeFi Stablecoin Analysis 🪙

A data analysis project exploring stablecoin dominance across blockchain networks using live on-chain data from DeFiLlama's API.

## What I Analyzed
- Which blockchains dominate stablecoin supply
- Market cap comparison of top stablecoins
- Chain market share breakdown

## Key Insights
- Ethereum controls 53% of all stablecoin supply
- Ethereum + Tron combined control 82% of the market
- USDT dominates with $189B vs USDC's $75B market cap
- Despite Solana's hype, it holds only 4.9% of stablecoin supply

## Tools Used
- Python
- Requests
- Pandas
- Matplotlib
- DeFiLlama API (free, no API key needed)

## Data Source
Live data pulled from DeFiLlama's stablecoins API
— reflects real time on-chain data
